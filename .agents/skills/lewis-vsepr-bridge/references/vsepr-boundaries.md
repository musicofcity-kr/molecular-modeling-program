# VSEPR Boundaries

## Separate concepts

| Concept | Meaning | Display location |
|---|---|---|
| 2D drawing coordinates | Page/canvas layout | editor |
| Connectivity | Atom-bond graph | validation summary |
| Lewis structure | Valence-electron representation | instructional overlay/panel |
| VSEPR model | Ideal local electron-domain geometry | separate model panel |
| Generated conformer | Computed coordinates | 3D viewer with method label |
| Curated/reference geometry | Source-backed value/coordinates | 3D/reference panel |

## Prohibited wording

- “2D 구조에 전자쌍 반발이 실제로 적용되었습니다.”
- “화면의 결합각이 실제 실험값입니다.”
- “사슬 전체가 하나의 VSEPR 모양입니다.”

## Preferred wording

- “2D 구조를 보기 좋게 정리했습니다.”
- “선택한 중심 원자 주변의 VSEPR 예상입니다.”
- “표시된 각도는 이상각/생성 좌표/참고값 중 어느 것인지 구분해 확인하세요.”
