# Classroom Language Bank v2

## Editor status

- 그리기 도구 준비 중
- 그리기 도구 준비됨
- 구조를 먼저 그려주세요
- 사슬 그리기 도움말
- 구조를 보기 좋게 정리하기

## Connectivity

- 원자 {A}개 · 결합 {B}개 · 하나의 구조로 연결됨
- 현재 구조가 {C}개의 조각으로 나뉘어 있습니다
- 원자 사이를 결합으로 연결해 주세요
- 빈 공간에 원자를 따로 놓으면 서로 결합되지 않을 수 있습니다

## Validation

- 구조 검증
- 검증 완료
- 검토 필요
- 계산을 위해 구조 검증이 필요합니다
- 현재 구조는 계산 가능한 분자 구조로 검증되지 않았습니다

## 2D and VSEPR

- 2D 구조식은 원자의 연결 관계를 나타냅니다
- 선택한 중심 원자 주변의 VSEPR 예상입니다
- 2D 구조를 정리하는 기능은 실제 3D 구조를 계산하는 기능이 아닙니다
- 사슬형 분자는 중심 원자마다 주변 구조를 따로 살펴볼 수 있습니다

## 3D and angles

- VSEPR 이상각
- 생성된 3D 좌표에서 측정한 각도
- 출처가 있는 참고 결합각
- 이 3D 구조는 개념 이해를 위한 모델입니다

## Ionic/mixture

- 이 활동은 서로 떨어진 이온을 포함할 수 있습니다
- 이 표기는 하나의 공유결합 분자가 아니라 이온의 조합을 나타냅니다
- 여러 물질을 함께 표시한 경우 하나의 분자식·분자량으로 단정하지 않습니다
