# 3D Viewer Checklist v2

- Does connectivity and RDKit validation pass first?
- Is the exact validated structure retained for handoff?
- Does the viewer clear old structures?
- Is source type explicit: VSEPR ideal, generated, curated, external, imported?
- Is coordinate source visible?
- Is structure match status known?
- Are angle labels ideal/generated/reference?
- Does a 2D edit invalidate stale 3D state?
- Is the model described as a model rather than direct experimental truth?
- Is a local VSEPR model distinguished from full-molecule conformation?
- Does it work on projector/mobile layouts?
