# 이용약관

`다양한 분자의 분자구조 모델링`(이하 "본 서비스")은 고등학교 화학 수업을
지원하기 위한 웹 애플리케이션입니다.

이 문서는 2026-07-27 작업 트리의 기능과 데이터 흐름을 설명하는 운영
초안입니다. 현재 변경분은 프로덕션 배포와 학교 운영 승인이 확인된 상태가
아닙니다. 실제 수업에서 서버 제출이나 외부 AI 처리를 활성화하기 전에는 학교
개인정보 담당자와 운영 책임자가 적용 법령·학교 규정, 운영 주체, 보유 기간,
삭제 절차와 사용하는 Firebase·AI 환경을 검토하고 배포 환경에 맞는 약관과
개인정보처리방침을 다시 게시해야 합니다. 이 문서는 법률 자문을 대신하지
않습니다.

## 제1조 목적

이 약관은 본 서비스가 제공하는 무료 교육용 기능의 이용 조건과 학생·교사·운영
주체가 지켜야 할 기본 원칙을 안내하는 것을 목적으로 합니다.

## 제2조 정의

1. "서비스"란 분자 구조 그리기, 구조 확인, 분자식·평균 분자량 표시, 참고
   3D 구조와 VSEPR 교육용 모형 비교, 수업 활동 기록·제출 및 교사 피드백
   기능을 말합니다.
2. "학생 이용자"란 수업코드, 입장 확인코드와 수업용 닉네임 또는 익명 ID로
   활동에 입장하는 이용자를 말합니다.
3. "교사 이용자"란 Firebase Auth와 교사 권한 확인을 거쳐 수업방과 제출
   자료를 관리하는 이용자를 말합니다.
4. "활동 결과"란 학생이 작성한 답변, 분자 구조 snapshot, 구조 확인 결과,
   3D 관찰·비교 내용과 정리 기록을 말합니다.
5. "서버 제출"이란 학생의 Firebase ID token, 수업 멤버십과 문서 소유권을
   trusted endpoint가 확인한 뒤 Firestore에 저장한 활동 결과를 말합니다.
6. "AI 피드백 초안"이란 교사가 검토·수정하기 위한 보조 자료를 말합니다.
   자동 채점 결과나 교사 확인 없이 학생에게 전달되는 최종 피드백을 뜻하지
   않습니다.

## 제3조 약관의 게시와 변경

1. 본 서비스는 이용자가 확인할 수 있도록 화면 하단에 이용약관과
   개인정보처리방침 링크를 제공합니다.
2. 운영 주체가 약관을 변경하는 경우 적용 예정일과 변경 사유를 서비스 화면
   또는 배포 문서로 안내합니다.
3. 실제 배포본의 기능, 외부 서비스, 보유 기간 또는 삭제 절차가 달라지면 해당
   환경에 맞게 약관과 개인정보처리방침을 함께 갱신해야 합니다.

## 제4조 제공 기능과 활성화 조건

본 서비스는 배포 설정과 이용 권한에 따라 다음 기능의 전부 또는 일부를
제공합니다.

1. Ketcher 기반 2D 분자 구조 입력
2. RDKit.js 검증을 통과한 구조의 분자식과 평균 분자량 표시
3. 3Dmol.js 기반 출처 표시 참고 3D 구조와 VSEPR 교육용 예상 모형 비교
4. 수업용 예제 분자와 활동 질문 제공
5. 이용자가 명시적으로 선택한 브라우저 활동 결과 저장·내보내기
6. Firebase Anonymous Auth 기반 학생 입장과 Firebase Auth 기반 교사 로그인
7. trusted endpoint를 통한 Firestore 수업 멤버십, 학생 제출, 교사 제출 목록
   조회와 피드백 반환
8. 서버 환경변수가 설정된 경우 외부 AI endpoint 또는 Gemini를 이용한 교사용
   피드백 초안 생성

Firebase·Vercel 환경변수, 교사 custom claim, 수업 멤버십 또는 Firestore
Security Rules가 준비되지 않은 배포에서는 서버 수업방·제출·피드백 기능을
사용할 수 없습니다. 핵심 분자 구조 학습 화면은 제한적으로 계속 사용할 수
있지만, 서버 저장 성공이 확인되지 않은 자료를 제출 완료로 보지 않습니다.

## 제5조 서비스 중단과 변경

1. 시스템 점검, 배포, 오류 수정, 외부 라이브러리·Firebase·PubChem·AI provider
   장애 또는 통신 장애로 일부 기능이 일시 중단될 수 있습니다.
2. PubChem 응답 또는 좌표 자료가 없으면 일부 참고 3D 구조를 표시하지 못할 수
   있습니다.
3. 서버 제출이 실패하면 현재 입력은 재시도를 위해 해당 학생 세션 메모리에
   남을 수 있지만, Firestore 저장 영수증이 없으면 제출 완료가 아닙니다.
4. 무료 교육용 프로토타입의 지원 범위와 책임은 실제 운영 공지, 적용 법령과
   학교 규정에 따라 판단해야 합니다.

## 제6조 학생 이용

1. 학생은 별도 회원가입 화면 없이 입장할 수 있지만, 서버 수업방을 사용하는
   환경에서는 내부 권한 확인을 위해 Firebase Anonymous Auth UID가 사용됩니다.
2. 학생은 실명, 학번, 전화번호, 이메일, 주소와 같은 불필요한 개인정보를
   수업용 닉네임이나 자유서술 답변에 입력하지 않아야 합니다.
3. 이용자가 명시적으로 저장한 로컬 활동 결과는 현재 브라우저의
   `localStorage`에 남을 수 있습니다. 이 기능은 교사에게 제출한 서버 자료와
   별개이며 서버 제출 성공 영수증이 아닙니다.
4. 학생 제출의 닉네임·답변·구조 snapshot 전체는 브라우저 제출함
   `localStorage` fallback에 저장하지 않습니다. 서버 저장 실패 시 입력을
   확인하고 다시 제출해야 합니다.
5. 학생은 같은 Firebase 수업방에서 본인 UID에 연결되어 교사가 반환한
   피드백만 확인할 수 있습니다.
6. 학생은 서비스 화면의 생성형 AI 윤리 안내와 교사의 수업 운영 안내를 확인한
   뒤 활동에 참여합니다.

## 제7조 교사 이용

1. 서버 수업방 관리 기능은 Firebase Auth 로그인과 `teacher: true` 또는
   `role: "teacher"` custom claim이 확인된 교사에게만 제공됩니다.
2. 긴급 로컬 교사 모드는 Firebase ID token을 발급하지 않으므로 서버 수업방
   생성, 제출 목록 조회 또는 Firestore 피드백 반환 권한으로 사용할 수
   없습니다.
3. 교사는 자신이 소유하거나 배정된 수업방의 제출만 조회하고 피드백을
   작성해야 합니다.
4. AI가 만든 피드백은 초안입니다. 교사는 과학 내용, 표현과 개인정보 포함
   여부를 확인하고 필요한 경우 수정한 뒤에만 학생에게 전달해야 합니다.
5. 교사는 실제 수업 전 학생·보호자에게 저장 위치, 외부 처리 여부, 보유 기간과
   삭제 요청 방법을 안내하고 학교의 필요한 검토·동의 절차를 확인해야 합니다.

## 제8조 외부 자료와 선택적 AI 처리

1. PubChem에는 검증된 canonical SMILES 또는 선택한 CID와 같은 화학 구조
   식별값을 보낼 수 있습니다. 학생 닉네임이나 답변은 PubChem 요청에 포함하지
   않습니다.
2. 서버에 AI provider가 설정된 경우 교사가 요청한 제출의 활동명, 분자명,
   구조 확인 요약과 학생 자유서술 답변 일부가 피드백 초안 생성을 위해 외부
   provider로 전송될 수 있습니다.
3. 자유서술에는 학생이 입력한 개인정보가 포함될 가능성이 있으므로 학생은
   불필요한 개인정보를 입력하지 않아야 하며, 교사와 운영 주체는 AI 기능을
   활성화하기 전에 입력 안내, provider의 처리 조건과 필요한 보호 절차를
   확인해야 합니다.
4. AI API key는 브라우저 번들에 두지 않고 서버 환경변수로 관리합니다.
5. AI 피드백은 점수·등급 산출이나 자동 채점 기능이 아니며, 교사 검토 전에는
   학생에게 자동 전달하지 않습니다.

## 제9조 저장, 보유와 삭제

1. 현재 탭의 미제출 답변과 파생 상태는 새 학생 세션, 역할·학생 identity 변경
   또는 앱 상태 초기화 시 삭제됩니다.
2. 이용자가 명시적으로 저장한 브라우저 활동 결과는 이용자가 앱에서
   삭제하거나 브라우저 사이트 데이터를 지울 때까지 남을 수 있습니다. 공유
   기기에서는 수업 종료 전에 삭제해야 합니다.
3. Firestore 수업 멤버십·학생 제출·교사 피드백에는 현재 자동 TTL과 학생용
   self-service 삭제 기능이 없습니다. 운영 주체는 실제 학생 자료를 수집하기
   전에 보유 기간과 Firebase 관리자 삭제 절차를 확정해야 하며, 해당 절차가
   준비되지 않은 환경에서는 서버 제출을 활성화하지 않습니다.
4. 이전 버전의 `molecule-workbench-activity-submissions` 브라우저 키는 앱 시작
   시 정리하도록 구현되어 있습니다.
5. 서버 자료의 열람·정정·삭제 요청 방법과 정보관리책임자 연락처는 배포본의
   개인정보처리방침에 게시해야 합니다.

## 제10조 이용자의 의무

이용자는 다음 행위를 하지 않아야 합니다.

1. 허위 내용 또는 타인의 개인정보 입력
2. 타인의 계정, 수업코드, 활동 결과 또는 피드백 도용
3. 서비스 화면·요청·데이터를 무단 변경하거나 운영을 방해하는 행위
4. 타인의 명예를 손상시키거나 불이익을 주는 내용 입력
5. 분자 구조 확인 결과, 참고 3D 자료 또는 VSEPR 예상 모형을 실험·문헌·최적화
   결과처럼 단정하여 사용하는 행위
6. 공개 저장소 또는 화면에 API key, service account, private token과 같은
   비공개 정보를 노출하는 행위

## 제11조 화학 정보, 저작권과 이용 범위

1. 분자식과 평균 분자량은 RDKit.js 구조 검증을 통과한 결과를 기준으로
   표시합니다.
2. 참고 3D 구조는 좌표 출처와 제공 방법에 따라 달라질 수 있으며 모든
   결합길이·결합각을 정밀 실험값으로 보장하지 않습니다.
3. VSEPR 예상 모형은 전자쌍 반발 이론을 이해하기 위한 교육용 모델이며 실제
   분자의 모든 전자 분포와 운동을 나타내지 않습니다.
4. 본 서비스는 화학 수업 이해를 돕는 도구이며 전문 연구, 의약품 개발,
   안전성 판정 또는 실험 설계의 단독 근거로 사용해서는 안 됩니다.
5. Ketcher, RDKit.js, 3Dmol.js, Firebase와 PubChem 자료에는 각 제공자의
   라이선스와 이용 조건이 적용됩니다.
6. 이용자는 학교 수업과 허용된 교육 목적 범위에서 활동 결과를 저장·인쇄·
   제출할 수 있습니다.

## 제12조 문의와 분쟁 처리

서비스 이용, 저장 자료 또는 개인정보 처리 관련 문의는 배포본
개인정보처리방침에 게시된 정보관리책임자에게 전달합니다. 분쟁이나 책임 범위는
당사자 간 협의와 적용되는 법령·학교 규정에 따라 처리하며, 이 약관이 법령상
보장되는 이용자의 권리를 제한하는 것으로 해석하지 않습니다.

## 부칙

- 적용 예정일: 2026년 7월 27일
- 변경 사유: Firebase Auth, trusted Firestore 제출·교사 피드백, PubChem과
  선택적 AI 처리, 보유·삭제 한계를 현재 작업 트리에 맞게 반영했습니다.
- 프로덕션 또는 학교 운영 전 실제 환경과 담당자 검토를 거쳐 다시
  게시해야 합니다.
